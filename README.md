# codingbat_java
CodingBat is a free website (codingbat.com) where students practice writing small Java functions and get instant feedback. It was created by Nick Parlante, a Stanford computer science lecturer, and it also supports Python. 

**IMPORTANT NOTE**
- Solutions will vary from person to person. Great opportunity to develop your own style of coding!
